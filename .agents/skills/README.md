# Skills de frontend, UI y UX

Este directorio contiene las nueve skills auditadas y vendorizadas desde `tobiasexequielperez11-cell/ai-andes-studio` en el commit `beaa169`.

Antes de utilizarlas, leer `../policy/USAGE.md` y `../../AGENTS.md`. Las skills no reemplazan el brief, la evidencia del producto, accesibilidad ni seguridad.

## Inventario

- `anti-ui-slop`: contrato de diseño y compuerta de terminación.
- `design-taste-frontend`: dirección visual amplia y selección de sistemas.
- `emil-design-eng`: detalle, componentes y motion.
- `frontend-design`: dirección distintiva y copy de interfaz.
- `high-end-visual-design`: exploración visual premium; uso no normativo.
- `ui-design`: variante compatible del stack UIZZE; redundante con `anti-ui-slop`.
- `ui-radar`: investigación visual externa opcional.
- `ui-ux-pro-max`: buscador local de estilos, UX, accesibilidad, tipografía y stacks.
- `web-design-guidelines`: revisión final; su referencia remota no se consume automáticamente.

Ver `../../docs/skills-audit.md` para hallazgos, licencias y compuertas.
